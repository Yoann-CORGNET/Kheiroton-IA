## 6. Méthodologie

### Score MCDA (Multi-Criteria Decision Analysis)

```
Score global = 0.25 × budget + 0.15 × juridique + 0.15 × technique
             + 0.10 × politique + 0.10 × timeline + 0.10 × social + 0.15 × impact
```

| Dimension | Poids | Source |
|-----------|-------|--------|
| Budget | 25% | Agent Économiste (coût, financement, compatibilité PSMT) |
| Juridique | 15% | Agent Juriste (constitutionnalité, droit UE, véhicule législatif) |
| Technique | 15% | Dérivé : moyenne(Économiste, Historien) |
| Politique | 10% | Dérivé : véhicule législatif + arithmétique AN |
| Timeline | 10% | Dérivé : délai réaliste (Historien) |
| Social | 10% | Agent Sociologue (acceptabilité sociale) |
| Impact | 15% | Agent Sociologue (impact socio-économique) |

### Limites

- Les scores reflètent une estimation de faisabilité, pas un jugement politique
- L'incertitude est élevée pour les mesures sans chiffrage indépendant
- Les interactions entre mesures (effets de synergie ou de contradiction) ne sont que partiellement capturées
- Le positionnement politique est une approximation basée sur les thèmes et mesures proposés
- Les données de référence sont principalement issues de la période 2022-2025

## Disclaimer

> Cette analyse est produite par un système automatisé utilisant l'intelligence artificielle.
> Elle s'appuie sur des données publiques et des méthodologies transparentes, mais ne remplace
> pas l'expertise humaine, le débat démocratique ou le jugement citoyen.
> Les scores de faisabilité sont des estimations avec des marges d'incertitude.

> Toute donnée utilisée est sourcée. Chaque score est accompagné d'un indice de confiance.
