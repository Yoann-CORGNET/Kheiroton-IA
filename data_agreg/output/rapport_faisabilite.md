| Critere | Poids |
|---------|-------|
| legal | 15% |
| budget | 25% |
| technical | 15% |
| political | 10% |
| timeline | 10% |
| social | 10% |
| impact | 15% |

### Echelle de notation

| Score | Label |
|-------|-------|
| 0.80+ | Tres faisable |
| 0.60-0.79 | Faisable |
| 0.40-0.59 | Partiellement faisable |
| 0.20-0.39 | Difficilement faisable |
| <0.20 | Irrealiste |

### Limites de la version POC

- Scoring heuristique (regles) au lieu d'agents LLM specialises
- Pas de RAG : les donnees contextuelles sont utilisees partiellement
- Pas de Monte Carlo pour les IC (simplification)
- Positionnement politique par mots-cles (production : LLM avec correlation >0.90)
- Pas de detection fine des contradictions inter-promesses
